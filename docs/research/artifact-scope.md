# Academic Artifact Scope

## Included

- Core execution model.
- Authority-separated receipts.
- Durable side-effect ledger semantics.
- Policy and approval invariants.
- Verification evidence model.
- Trust-aware memory promotion rules.
- Workspace stale-read/conflict mediation.
- Failure-injection evaluation protocol.

## Excluded

- Product installer UX.
- Desktop application packaging.
- Marketing pages.
- Provider-specific model branding.
- Appwrite deployment helpers.
- Release-store publication steps.
- Claims based only on local benchmark suites.

## Relationship to the product branch

The product branch contains the full engineering system. This academic branch defines the research kernel and paper-facing artifact. If code is reintroduced later, it should be the minimal reproducible implementation required for the evaluation protocol, not the full product.
