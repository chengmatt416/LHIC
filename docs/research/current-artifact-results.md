# Current Artifact Results

## Invariant tests

The current artifact contains six executable invariant tests:

1. planner cannot lower independently inferred risk;
2. high-risk action cannot use reusable origin scope;
3. verification requires independent non-empty evidence;
4. ambiguous side effect is not blindly retried;
5. verified action identity cannot be dispatched again;
6. trusted skill promotion requires three independent verified task IDs.

Expected result: `6 passed, 0 failed`.

## Deterministic synthetic failure injection

The included harness runs 100 deterministic trials per strategy over five synthetic failure modes. Current reference output:

## Interpretation

The harness demonstrates the intended safety/availability trade-off in the reference semantics:

- naive retry preserves nominal completion but can duplicate external effects;
- verification without durable ambiguity state reduces but does not eliminate duplicates in the injected model;
- a durable ledger can eliminate duplicate replay but may defer too many cases to human resolution;
- combining ledger state with observation and verification reduces duplicate replay while recovering more ambiguous cases automatically.

These numbers are generated by a deliberately small deterministic simulator. They do **not** establish real-world effectiveness, statistical significance, or superiority on OSWorld, SWE-bench, tau-bench, or any other external benchmark.

## Publication rule

A paper may use this harness as internal-validity evidence for state-machine behavior. Any claim about practical agent reliability should additionally report real environment experiments, repeated trials, uncertainty intervals, and official benchmark outputs where available.
