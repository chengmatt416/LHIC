# 參與者操作說明——LHIC LearnLoop 離線意圖研究

版本：`[INSTRUCTION_VERSION]`

本說明只提供給已通過核准並完成同意程序的參與者，不能取代參與者說明與同意書。

## 開始前

- 只使用研究操作人員提供的裝置、瀏覽器設定檔與研究頁面。
- 不要登入真實個人帳號。
- 不要輸入真實密碼、私人訊息、付款資料、醫療資料、學校識別碼、政府識別碼或其他敏感資訊。
- 只使用研究操作人員提供的虛構資料。
- 任務不清楚時，先詢問再繼續。
- 你可以暫停、跳過任務或隨時停止。

## 每個任務進行時

1. 閱讀研究操作人員顯示的任務。
2. 確認頁面是研究測試環境，而且不需要真實個人資料。
3. 只完成指定任務，不要探索無關控制項。
4. 除非核准的任務明確要求，否則不要開啟其他分頁、其他帳號、開發者工具、原始碼或私人 log。
5. 你認為任務完成時告知操作人員。
6. 不要嘗試改善、修正或解釋模型預測；研究要在固定程序下測量軟體。

## 發生以下情況時立即停止

- 頁面要求真實憑證或敏感資訊；
- 頁面看起來會影響真實服務、帳號、付款、預約、訊息或公開貼文；
- 出現非預期內容；
- 你感到不舒服、困惑或受到壓力；
- 操作人員要求你做核准說明以外的事情。

停止不會受到處罰。

## 軟體會記錄什麼

核准的資料集只記錄假名化雜湊與受限制的決策／時間測量。不得記錄你的姓名、聯絡方式、原始任務文字、原始頁面文字、螢幕截圖、網址、selector、密碼、私人訊息或自由文字說明。

若你認為任何禁止資訊被記錄，請立即告知操作人員。

## 退出研究

你可以依同意書中的聯絡方式與程序要求退出。研究團隊會使用另外保存、受限制的對照表找到你的研究代碼。退出處理仍受同意書中說明的界線限制，包括已公開 aggregate results 的處理界線。

## Session 結束後

不要分享任務截圖、restricted schedule、參與者代碼或研究檔案。除非負責督導另有明確保密規定，你可以描述一般使用感受。
